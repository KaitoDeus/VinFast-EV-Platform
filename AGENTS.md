# VinFast EV Platform - AGENTS.md

Instructions and guidelines for AI agents working in this codebase:

## Stack Overview
- **Next.js 16.3** App Router
- **Tailwind CSS v4** with CSS Variables
- **TypeScript 5**
- **Lucide React** Icons

## Mandatory Rules
- **Dashboard Theme**: The dashboard is strictly Dark Mode (`#1f1f1f`).
- **Data Flow**: Import types from `@/types` and mock data from `@/data`.
- **Quality**: Always verify TypeScript compilation (`npx tsc --noEmit`) before completing tasks.
